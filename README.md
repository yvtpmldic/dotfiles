# dotfiles

Personal configuration files for macOS and iTerm2.

## Contents

- `.zshrc` — shell aliases and prompt
- `.gitconfig` — global git settings
- `.vimrc` — minimal vim tweaks
- `.iterm2/` — profile and keybindings

## Setup

Clone and run `./install.sh` (symlinks configs into `$HOME`).

## Notes

- Uses `zsh` with `oh-my-zsh`
- Add machine-specific overrides in `~/.zshrc.local`
